# Система управління бібліотекою відеоігор

## Опис проєкту

Проєкт присвячений розробці системи для управління особистою бібліотекою відеоігор. Користувачі зможуть переглядати каталог ігор, шукати потрібні ігри, додавати їх до власної бібліотеки та залишати відгуки.

## Основні можливості

- Перегляд каталогу відеоігор.
- Пошук ігор за назвою та жанром.
- Створення особистої бібліотеки ігор.
- Додавання та видалення ігор із бібліотеки.
- Написання та перегляд відгуків.

## Мета роботи

Визначити функціональні та нефункціональні вимоги до системи, описати основні сценарії використання та побудувати зв'язок між вимогами і сценаріями.

## Структура проєкту

- `README.md` — опис проєкту.
- `spec.md` — специфікація вимог і сценаріїв використання.
- `uc-diagram.puml` — діаграма варіантів використання.
- `DEFENSE.md` — обґрунтування прийнятих рішень.
