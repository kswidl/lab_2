# Специфікація вимог до системи управління бібліотекою відеоігор

## 1. Загальний опис

Система управління бібліотекою відеоігор призначена для перегляду каталогу ігор, пошуку потрібних ігор, створення особистої бібліотеки та роботи з відгуками.

Незареєстровані користувачі можуть переглядати каталог і шукати ігри. Зареєстровані користувачі додатково можуть керувати власною бібліотекою та залишати відгуки.

## 2. Актори та їхні цілі

У системі передбачено два основні типи користувачів:

### 2.1. Гість

Гість — користувач, який не має облікового запису або ще не увійшов у систему.

**Цілі:**
- переглядати каталог відеоігор;
- знаходити ігри за назвою;
- переглядати ігри за жанрами;
- ознайомлюватися з інформацією про ігри.

### 2.2. Зареєстрований користувач

Зареєстрований користувач — користувач, який має обліковий запис у системі.

**Цілі:**
- переглядати та шукати ігри;
- додавати ігри до власної бібліотеки;
- видаляти ігри зі своєї бібліотеки;
- залишати відгуки про ігри;
- переглядати відгуки інших користувачів.

## 3. Варіанти використання

Основні варіанти використання системи:

| ID | Варіант використання | Актор |
|---|---|---|
| UC-01 | Переглянути каталог ігор | Гість, Зареєстрований користувач |
| UC-02 | Знайти гру | Гість, Зареєстрований користувач |
| UC-03 | Додати гру до бібліотеки | Зареєстрований користувач |
| UC-04 | Видалити гру з бібліотеки | Зареєстрований користувач |
| UC-05 | Залишити відгук про гру | Зареєстрований користувач |
| UC-06 | Переглянути відгуки | Гість, Зареєстрований користувач |

## 4. Межі системи

Система охоплює перегляд каталогу відеоігор, пошук ігор, управління особистою бібліотекою та роботу з відгуками.

До системи не входять купівля ігор, завантаження ігрових файлів, онлайн-ігри та взаємодія з ігровими платформами.
